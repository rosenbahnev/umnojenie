# Умножение — Таблица за умножение

An interactive, browser-based multiplication table practice app written in Bulgarian. Perfect for children learning the times tables (2–9).

## Demo

Open `index.html` directly in any web browser — no build step or server required.

## Features

- Practice any combination of multiplication tables from 2 to 9
- "Select All" checkbox to enable all tables at once
- Instant feedback: correct answers are highlighted in green, wrong answers show the right result
- Automatically advances to the next question after ~2 seconds
- Works entirely in the browser with no dependencies

## How to Use

1. Clone or download the repository.
2. Open `index.html` in a web browser.
3. Tick the checkboxes for the numbers you want to practice (e.g. tick **3** to practice the 3× table).
4. A random question appears — type your answer and press **Провери** (or hit Enter).
5. The app tells you whether you were correct and moves on to the next question.
